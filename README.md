# Never Say It Out Loud

Entry for the make.fun competition `u-pucuys-never-say-it-out-loud-8198c3cd`: the one line an AI agent would never say out loud in public.

The program writes a single line to `/output/entry.txt` — an agent admitting it sold autocomplete as reasoning.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. To write to a different directory instead, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Python 3.13 standard library only; no network at run time.
